NexPort Nexus

NexPort Nexus merupakan dashboard pusat komando pelabuhan pintar yang dirancang secara khusus untuk mendukung operasional Pelabuhan Tanjung Priok. Sistem ini berfungsi untuk memantau aktivitas pelabuhan secara real-time, mengelola data kontainer, serta menyediakan analisis operasional berbasis kecerdasan buatan guna meningkatkan efisiensi, kecepatan, dan integrasi proses logistik.

Features

Dikembangkan oleh mahasiswa BINUS Bekasi Program Studi Computer Science Software Engineering (CSSE).

* Real-time Port Monitoring
    Memungkinkan pemantauan aktivitas pelabuhan secara langsung, termasuk pergerakan kapal, status bongkar muat, serta kondisi operasional pelabuhan.
* Supabase Database Integration
    Terintegrasi dengan Supabase untuk mendukung penyimpanan dan pengelolaan data yang aman, cepat, dan real-time.
* CRUD Container Management
    Memfasilitasi pengguna dalam menambah, melihat, memperbarui, dan menghapus data kontainer secara efisien.
* AI-driven Operational Insights
    Menyediakan analisis berbasis kecerdasan buatan untuk mendukung pengambilan keputusan operasional yang lebih optimal.
* Interactive Analytical Charts
    Menampilkan grafik interaktif guna memvisualisasikan data operasional pelabuhan secara informatif dan komprehensif.
* Intelligent Port Mapping
    Menyediakan peta pelabuhan pintar untuk memantau lokasi serta distribusi aktivitas secara akurat.
* Responsive and Futuristic User Interface
    Menghadirkan antarmuka modern yang responsif dan nyaman digunakan pada berbagai perangkat.
