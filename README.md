# NexPort Nexus

NexPort Nexus is a smart port control center dashboard designed for real-time logistics, fleet, and shipment monitoring operations at Tanjung Priok Port.

## Main Features

* Real-time container monitoring
* Vehicle & driver management
* Smart analytics dashboard
* Tactical SVG congestion map
* Realtime Supabase integration
* KPI monitoring system
* Export CSV functionality
* Activity feed & smart alerts
* Responsive enterprise UI

## Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Supabase
* Chart.js

## Modules

* Container Registry
* Fleet Hub
* Driver Monitoring
* Shipment Analytics
* Tactical Port Map
* Notification & Alert System

## Responsive Support

* Desktop
* Tablet
* Mobile
